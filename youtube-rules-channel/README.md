# The Residents' Office: YouTube "Rules" Channel Kit

A research, scripting and production kit for a minimalist "If Your ___ Ever ___… DO NOT ___" rules-horror channel. The format is modeled on Bradikinin (@BradikininVideos), with its own original identity.

| [`03-visual-style-guide.md`](03-visual-style-guide.md) | Palette, fonts, frame layout, thumbnail formula, motion recipe |
